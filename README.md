## Bigger is happier, Isn't that so?

This mod changes the happiness penalty based on settlement size to a happiness bonus.

| Number of Settlers | Happiness | 
| ------------------ |-----------| 
| ~5                 | +0        | 
| ~11                | +10       | 
| ~17                | +20       | 
| ~23                | +30       | 
| 24~                | +40       |
